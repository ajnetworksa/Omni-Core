---
description: End of a work session — leave the project ready for the next person or AI
---

1. Run `npm run verify` and keep the REPORT.md table.
2. Update `docs/HANDOFF.md`: date, version, what you changed this session, the verify table,
   what is NOT verified, open problems, and the next suggested steps.
3. Update `docs/PROGRESS.md` if a feature is finished, `CHANGELOG.md` for user-visible changes.
4. `git status`: list what the user needs to commit. Suggest a commit message.
5. Final message: summary + the verify table + the commit commands.
